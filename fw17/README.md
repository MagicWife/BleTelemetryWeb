# FW17 蓝牙调试与 OTA

新增独立入口 `fw17/index.html`，旧首页与现有CityU的42字节v2功能保留。此页适配 Petvewi FW17、协议v7、schema2、31维特征。

## 打开网页

在仓库目录运行 `node fw17/serve.mjs`，使用桌面Chrome/Edge访问 `http://127.0.0.1:4173/fw17/`。也可部署到仓库原有静态托管，在原站地址后追加 `/fw17/`。无需安装依赖或构建。不能通过file://直接使用ES模块及示例加载。Web Bluetooth要求HTTPS或localhost；支持情况以当前浏览器与操作系统为准。浏览器/应用内WebView可能不支持蓝牙。

## 查看遥测

1. 点击“连接蓝牙设备”，选择Petvewi设备。网页请求主服务及OTA服务访问权限。
2. 订阅data通知后接收；必要时点击“开始推流”。状态面板读取固件测得的ATT MTU，实时168B通知至少要求MTU171，设备请求247，网页不能直接强制设置MTU。
3. 约2秒后前27维核心可用，约4秒后31维完整。静息/未佩戴时无效值显示为“—”，不会误把占位零当作运动。4秒历史允许混合状态；页面显示1秒与4秒混合标记。
4. 频谱无能量时对应频谱组显示无效。周期窗口有效但未找到正峰时，周期强度/频率为有效零，查看FOUND标记区分。
5. “开始记录”记录之后收到的有效解析帧；历史帧也可记录，但没有31维。最多20000条内存记录，达到上限暂停记录，需导出。CSV包括记录ID、UTC接收时间、设备时间、有效标记、31维及完整HEX；无效特征为空。重复缓存快照不作为新记录；超过3秒没有新记录或断开连接时，当前读数显示过期并清空，趋势保留历史。刷新页面将丢失未导出的记录。
6. “载入示例”加载FW17实际C序列化器产生的168字节样例，仅用于界面/解析检查；明确标记为示例，并不会连接设备或操作OTA。

当前活动码只有0未知/未佩戴、2静息、6睡眠、7活动，31维不是云端行为分类结果。页面不根据特征自行生成理毛/食饮等标签。电池字段为原始ADC，不推算电量百分比；诊断health 0x0200显示为低电压(<3.5V)。

## OTA

仅上传 `FW17_Petvewi002_OTA_APP_NEW_LAYOUT_ONLY.bin` 等匹配设备的应用镜像。不得上传 FULL_BURN、A区或源码ZIP。页面校验向量表、唯一OTA契约、分区ID `0x02000001`、A ABI1及CRC `E9A4172A`、文件长度、契约CRC和设备名。应用CRC32使用标准zlib算法。

- 连接后通过OTA通知特征的只读值获取16B持久安装结果及真实运行版本；厂商VERSION_INFO特征固定返回`00 01`，不能当作FW版本。
- 开始前勾选设备/镜像确认。只有明确开始OTA时发送GET_BASE，避免连接时触发OTA会话并暂停采样。
- FW15/旧布局须先有线烧录新布局。FW16同布局设备可在本页升级，但本页不解析v6遥测。设备暂存地址必须为`0x68000`，否则禁止擦写。
- 只擦除应用长度覆盖的C区4KiB扇区，每条擦除/写入等待匹配ACK；写入地址严格连续。数据块上限`min(MTU-3,244)-9`，MTU23时为11字节，MTU247时235字节。不会使用全片擦除、内存写或盲目重发。
- 最后提交`0x09`及应用长度/CRC。最后ACK可能在重启时丢失，此时显示“待重连核对”，不宣称成功。中途断开会停止上传，没有断点续传；重新上传从头擦写C区。
- 重连同一设备并读取安装结果，检查SUCCESS、运行版本、目标版本和目标CRC；浏览器仅保存这次目标元数据用于匹配，不保存固件文件。不能把断开连接、传输100%或旧成功记录当作本次安装成功。同版本同CRC重装遇到既有相同SUCCESS，明确提示无法单凭持久结果区分上次安装事件。
- OTA期间禁用遥测命令、状态轮询和镜像选择。未提交失败后，设备通常在10秒会话超时后恢复采样；可断开后重新连接。

设备端仍执行实际A区CRC及契约检查；网页预检不替代固件校验。此实现经过模拟协议和本地真实镜像解析验证，未连接设备执行实际擦写/升级。首次使用需现场核对设备与串口日志。

## 测试

`npm run test:fw17` 或 `node --test fw17/tests/*.test.mjs`。测试包含C生成帧、逐字节CRC破坏、任意通知分片、错误schema、预热有效性、缓存去重、镜像预检、OTA逐包应答、断开/错误ACK/旧分区保护、重连结果核对。可设置`FW17_IMAGE`为本机实际OTA_APP路径，额外校验交付镜像；未设置时该项跳过，其他测试不依赖固件目录。

`node fw17/serve.mjs`供本地预览；测试不连接真实设备。数据、CSV及文件处理在浏览器本机进行，网页没有遥测上传接口、第三方CDN或分析脚本。
